# esp32s3-I2S-Audio-player-from-SD-and-USB
# ESP32-S3 USB Player

Проигрыватель аудиофайлов с USB-флешки и microSD-карты. Управление выполняется из браузера через Wi‑Fi.

Проект рассчитан на ESP32-S3 с 8 МБ PSRAM. Таблица разделов подходит для flash 8 МБ и больше, OTA не используется.

## Возможности

- воспроизведение MP3/WAV и других форматов, поддерживаемых `ESP32-audioI2S`;
- чтение файлов с USB-флешки;
- чтение файлов с microSD по SPI;
- управление из браузера: выбор файлов, воспроизведение, пауза, громкость, перемотка и копирование;
- настройка Wi‑Fi через собственную точку доступа;
- один factory-раздел прошивки без OTA.

## Что понадобится

- плата ESP32-S3 с 8 МБ PSRAM;
- USB-разъём или USB-OTG-переходник для подключения флешки;
- держатель microSD или SD-модуль с поддержкой SPI;
- I2S DAC/усилитель, например MAX98357A или аналогичный модуль;
- источник питания 5 В с достаточным током;
- USB-кабель для прошивки;
- компьютер с Windows, macOS или Linux.

Важно: ESP32-S3 работает с USB 2.0 только в режиме Full-Speed — до 12 Мбит/с. Это не USB High-Speed 480 Мбит/с.

## Подключение

Все сигнальные уровни ESP32-S3 — 3,3 В. Земля ESP32, SD-модуля, DAC и USB-питания должна быть общей.

### microSD по SPI

| ESP32-S3 | SD-модуль | Назначение |
|---|---|---|
| GPIO39 | CS/SS | выбор карты |
| GPIO41 | SCK/CLK | тактовый сигнал SPI |
| GPIO40 | MOSI/DI | данные от ESP32 к карте |
| GPIO42 | MISO/DO | данные от карты к ESP32 |
| 3V3 | VCC | питание карты |
| GND | GND | общий минус |

Подключение в SPI-режиме должно быть именно таким: `MOSI → DI`, `MISO → DO`, `SCK → CLK`, `CS → CS`.

Не подавайте 5 В непосредственно на выводы ESP32 или на вывод MISO. Если используется 5-вольтовый SD-модуль, убедитесь, что в нём есть корректный преобразователь уровней. Для длинных проводов желательно поставить последовательно в SCK/MOSI/CS резисторы 22–47 Ом и установить подтяжки CS/MOSI к 3,3 В через 10 кОм.

В текущей прошивке SD запускается на 20 МГц. Если карта не определяется, для проверки временно снизьте частоту в `src/main.cpp` до 1–4 МГц.

### I2S DAC

| ESP32-S3 | DAC | Назначение |
|---|---|---|
| GPIO16 | BCLK/BCK | тактирование I2S |
| GPIO17 | DIN/DATA | аудиоданные |
| GPIO18 | LRCLK/WS/LCK | выбор левого/правого канала |
| 3V3 или 5V | VIN | по документации конкретного DAC |
| GND | GND | общий минус |

У разных I2S-модулей названия входов отличаются. `DOUT` в конфигурации ESP32 означает выход данных ESP32, поэтому он подключается к `DIN` или `DATA` DAC.

### USB-флешка

USB-флешка подключается к USB-OTG host-разъёму платы. Для ESP32-S3 используются аппаратные линии USB:

```text
GPIO19 — USB D-
GPIO20 — USB D+
```

Если USB-разъём собирается самостоятельно, соблюдайте правильную разводку D+/D−, используйте короткие дифференциальные дорожки и предусмотрите защиту VBUS. Не подключайте питание флешки к GPIO ESP32. Флешка может потреблять значительный ток при запуске.

## Подготовка microSD и USB

Для максимальной совместимости используйте FAT32. Для карты 64 ГБ рекомендуется создать один раздел MBR и отформатировать его в FAT32 с размером кластера 32 КБ.

Перед использованием новой карты проверьте её полной записью/чтением через H2testw или F3. Поддельные карты часто сначала определяются, а затем выдают ошибки чтения.

Поддерживаемые файлы положите в корень или папки на SD/USB. После подключения накопителя откройте веб-интерфейс и выберите нужный файл.

## Установка PlatformIO

1. Установите Visual Studio Code.
2. Установите расширение **PlatformIO IDE**.
3. Откройте в PlatformIO корневую папку проекта — папку, где находятся `platformio.ini`, `src`, `include` и `lib`.
4. Подключите ESP32-S3 по USB.
5. Дождитесь установки зависимостей.

Из терминала PlatformIO можно выполнить:

```bash
pio run
```

Если команда `pio` не найдена, используйте терминал PlatformIO внутри VS Code.

## Первая прошивка

Для первого запуска рекомендуется стереть старую flash-разметку:

```bash
pio run -t erase
pio run -t upload
```

Обычная последующая прошивка:

```bash
pio run -t upload
```

Монитор порта:

```bash
pio device monitor -b 115200
```

В PlatformIO адреса бинарных файлов такие:

```text
bootloader.bin   0x0000
partitions.bin   0x8000
firmware.bin     0x10000
```

Обычно вручную прошивать их не требуется — команда `pio run -t upload` делает это автоматически.

## Первый запуск Wi‑Fi

Если сохранённых настроек Wi‑Fi нет, ESP32 создаёт открытую точку доступа:

```text
ESP-Player-Setup
```

1. Подключитесь к этой сети телефоном или компьютером.
2. Если страница не открылась автоматически, перейдите на:

   ```text
   http://192.168.4.1/
   ```

3. Нажмите сканирование сетей.
4. Выберите свою сеть.
5. Введите пароль и нажмите сохранение.
6. ESP32 перезапустится и подключится к выбранной сети.

После подключения адрес плеера печатается в Serial Monitor, например:

```text
WiFi OK, открой в браузере: http://192.168.0.143/
```

Телефон и ESP32 должны находиться в одной Wi‑Fi сети. Если IP изменился после перезапуска, смотрите новый адрес в Serial Monitor или закрепите IP за ESP32 в настройках роутера.

## Если нужно заново настроить Wi‑Fi

Очистите flash и прошейте проект снова:

```bash
pio run -t erase
pio run -t upload
```

После очистки снова появится точка доступа `ESP-Player-Setup`.

## Диагностика

### SD-карта не определяется

Сообщения вида:

```text
GO_IDLE_STATE failed
f_mount failed: (3) The physical drive cannot work
```

означают, что ESP32 не получил ответ от карты на физическом уровне. Проверьте питание 3,3 В, общий GND, CS, MOSI/MISO, длину проводов и преобразователь уровней. На этом этапе формат FAT32 ещё не является причиной ошибки.

### Wi‑Fi не подключается

- сеть должна работать в диапазоне 2,4 ГГц;
- проверьте пароль;
- временно отключите изоляцию клиентов Wi‑Fi в роутере;
- после трёх неудачных попыток снова подключитесь к `ESP-Player-Setup`;
- при необходимости выполните полную очистку flash.

### USB-флешка не определяется

- используйте короткий качественный USB-переходник;
- проверьте питание VBUS;
- попробуйте небольшую флешку USB 2.0;
- отформатируйте её в FAT32;
- не подключайте флешку через пассивный разветвитель;
- начальная ошибка USB при подключении иногда исчезает после повторного подключения.

### Ошибка `No core dump partition found`

В текущей таблице разделов coredump не используется. Это предупреждение не мешает работе USB, SD или Wi‑Fi и его можно игнорировать.

### Накопитель подключён, но список пуст

Проверьте, что накопитель смонтирован, файлы имеют поддерживаемое расширение, а имена файлов не содержат повреждённых символов. Для диагностики откройте Serial Monitor со скоростью 115200.

## Настройки проекта

Основные GPIO и параметры находятся в [`include/config.h`](include/config.h). Таблица flash-разделов — в [`partitions.csv`](partitions.csv), настройки PlatformIO — в [`platformio.ini`](platformio.ini).

Текущая разметка flash:

```text
factory — 5 МБ
SPIFFS  — около 3 МБ
OTA     — отсутствует
```

Разметка помещается в 8 МБ flash и также может использоваться на платах с 16 МБ flash; лишнее место на 16-МБ плате останется свободным.


D+ 20

Также подключить питание ко всем устройствам в зависимости от модификации. USB подать 5 волбт.
